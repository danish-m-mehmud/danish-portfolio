## Context

Facility operators needed a shared view of HVAC, surveillance, lighting, and fire-safety systems.

## What I delivered

I built a React and Node.js monitoring platform. MQTT carried system telemetry, and Socket.IO delivered live updates to the operator interface.

## Production outcome

Operators could see telemetry from all four building systems in a single real-time view.
