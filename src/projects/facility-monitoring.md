## Operator visibility

I built a real-time platform for facility operators to monitor HVAC, surveillance, lighting, and fire-safety systems in one place. MQTT carried system telemetry and Socket.IO delivered live updates to the React interface.

**Stack** · React, Node.js, MQTT, Socket.IO
